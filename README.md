# GeneWeaver

Python project for DNA guide and target sequence processing.

## Requirements
- Python 3.10 or later
- pip

## Setup (Windows PowerShell)

1. Create virtual environment:
   `py -m venv .venv`

2. Activate:
   `.\.venv\Scripts\Activate.ps1`

3. Install dependencies:
   `pip install -r requirements.txt`

4. Run application:
   `python app.py`

5. Deactivate:
   `deactivate`

Expected output: `Welcome to GeneWeaver!`

See GPU_ENVIRONMENT.md for hardware and acceleration details.
